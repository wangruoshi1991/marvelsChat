# 公开图库中文检索测试结果

2026年11月10日，使用60张公开照片与20条预先固定的中文描述进行测试。目标照片排在第一位的有19条，在前5张找到目标照片的有20条。另有3条不存在目标内容的诊断题，它们仍返回了相似照片。

## 测试集

图片共约19.08 MiB，分为猫、狗、人物活动、城市与建筑、自然风景、食物6类，每类10张。已目视核查并替换无关图片、插画、宣传拼贴与部分近重复图片。图库仍保留若干相似场景，用来测试细节区分。

所有图片来自Wikimedia Commons，许可包含CC0、公共领域、CC BY和CC BY-SA。逐图署名与许可见 ATTRIBUTION.md，完整来源见 SOURCES.json。图片、描述和人工选择的参考照片在检索前固定；查询文件校验值保存在 results.json。

## 已观察到的边界

蓝色圆窗与吊灯的查询中，目标照片排第二；第一张是另一张有圆形窗与灯光的室内建筑照片，说明相似构图中的细节仍可能混淆。

3条不存在目标的描述分别是海底潜水员、生日蛋糕蜡烛、机场跑道上的大型客机。当前实现总是返回相似度最高的照片，不会据此自动判定未找到。此问题需要后续校准阈值或增加结果复核；3条诊断题未计入正例命中率。

此测试为小规模、人工挑选、描述较明确的公开样本。没有验证在个人相册中的模糊回忆、人物身份、日期、地点或几千张相近照片上的表现，也未排查这些公开照片是否出现在模型训练数据中。不能把本次命中率视为个人相册准确率。

## 使用

项目中双击 start-public-demo.command 后打开 http://127.0.0.1:8766。公开测试相册与个人相册分开存储，可直接输入上表描述试用。

独立素材包中的 images 文件夹也可直接导入任何新相册。ATTRIBUTION.md、SOURCES.json、queries.json和results.json应随图片一起保留。

若要重新运行测试，在独立测试服务启动后，从项目目录执行：

```sh
.venv/bin/python tests/evaluate_public_library.py
```

界面代码与接口已检查；当前桌面锁定，未完成浏览器中的视觉检查。
