# 媒体检索 Agent 风险评估

- Manifest version: `0.1.0`
- 风险等级: `R2`
- 生命周期: `draft`

## 类型配置档

| Profile | 结论 | 证据 |
| --- | --- | --- |
| synchronous-tool | 是 | 状态与搜索读取为受控同步操作。 |
| asynchronous-generation | 是 | 回填、索引、重建与清除使用可恢复任务。 |
| external-provider | 是 | 仅服务端可调用阿里云百炼的受控模型适配层。 |
| paid | 是 | 调用默认关闭，需确认、预算预留和未知计费停机。 |
| sensitive-data | 是 | 私有媒体及其派生描述、OCR 和向量受用户同意与删除控制。 |

## 最小权限

| Scope | 用途 | 撤销方式 |
| --- | --- | --- |
| `private-media:read` | 读取已认证用户自己的已上传素材。 | 用户停用索引、素材删除或账户删除。 |
| `private-media-index:write` | 写入可删除的派生段和作业状态。 | 停用后立即不可查询并排队清除。 |
| `agent-runs:read` | 用户查看自己的脱敏进度事件。 | 所有查询使用服务端用户范围。 |

## 成本和副作用

外部调用默认关闭，运行时预算初始为零。每个用户每天至多三次可触发外部调用的根动作，全局日预算上限为 1,000 分，告警阈值为 80%。未知计费或超时后不自动重试。索引会写入派生描述和向量；停用、素材软删除和账户删除均必须先让它们不可查询，再完成物理清除。

## 风险结论

用户确认必需，独立人工复核在 sandbox 或更高生命周期前必需。当前单人负责状态只允许本地、无付费、无真实用户数据的实现和自动化测试。
