# 媒体检索 Agent 运行手册

## 初始状态

保持以下默认值：新运行关闭、外部模型调用关闭、生命周期为 `draft`。迁移 034 后用户日额度、用户月预算和全局日预算为 `NULL`，表示无上限；值为 `0` 表示阻断，不得把两者混淆。启用时必须有正数的逐操作预留额、显式无上限批准和人工 Provider 关闭开关。不得通过客户端、命令行参数或日志传递密钥。

## 进入 sandbox 前检查

1. 独立 Security Reviewer 和 Release Owner 已登记。
2. 数据库迁移、向量扩展、对象存储、Worker 心跳和安全运行状态均通过。
3. 版本化 30-case mock-only synthetic contract、授权隔离、删除、费用预留和恢复测试全部通过。另须单独记录 held-out 真实素材模型质量评测；synthetic contract 通过率不能作为检索相关性或模型质量证据。
4. 发布候选的生产依赖审计无未处置 Critical/High；例外必须由独立 Security Reviewer 记录可达性、影响及接受理由。React Native/Metro/Jest 依赖迁移需在 iOS 与 Android 构建后再发布。
5. Mock smoke 通过；真实付费校准有明确的批准记录、数据集/执行范围、费用承担方和停止条件。产品策略不设次数或金额硬上限时，不得私自加回封顶值；必须明确记录未封顶费用接受、供应商账单核对责任、人工 Provider kill switch 和未知计费时的停止规则。
6. 管理端可关闭新运行、外部调用和队列消费，且不显示密钥或对象路径；当前没有自动费用熔断，启用前必须确认运营方接受未封顶的供应商费用并有值守处置安排。

## 常见处置

- 成本异常：费用没有自动硬上限；立即通过管理端关闭 Provider 调用，保留脱敏账本并与供应商账单对账，禁止自动重试未知计费任务。
- 删除失败：保持相关段不可查询，继续清除任务，不恢复搜索可见性。
- Worker 异常：停止新任务，使用 checkpoint 从最近安全边界恢复，避免重复写入和重复计费。生产单元只在失败时重启，300 秒内最多启动 5 次；达到限制后先修复明确依赖故障，再由运维人员手动 reset/start，不得绕过启动限制。
- 可疑越权：关闭新运行，撤销受影响会话，审查仅含 trace ID 的安全事件。

## 退出和清理

停用时先禁止新任务和检索可见性，再创建可审计清除运行。完成后删除派生描述和向量，保留脱敏运行事件 180 天及聚合成本数据 24 个月。
