# 媒体检索 Agent 运行手册

## 初始状态

保持以下默认值：新运行关闭、外部模型调用关闭、用户日额度为零、全局预算为零、生命周期为 `draft`。不得通过客户端、命令行参数或日志传递密钥。

## 进入 sandbox 前检查

1. 独立 Security Reviewer 和 Release Owner 已登记。
2. 数据库迁移、向量扩展、对象存储、Worker 心跳和安全运行状态均通过。
3. 30 条评测、授权隔离、删除、预算和恢复测试全部通过。
4. Mock smoke 通过；真实付费校准有单独的批准记录、调用上限和预算上限。
5. 管理端可关闭新运行、外部调用和队列消费，且不显示密钥或对象路径。

## 常见处置

- 预算或计费异常：立即关闭外部模型调用，保留脱敏账本，禁止自动重试未知计费任务。
- 删除失败：保持相关段不可查询，继续清除任务，不恢复搜索可见性。
- Worker 异常：停止新任务，使用 checkpoint 从最近安全边界恢复，避免重复写入和重复计费。
- 可疑越权：关闭新运行，撤销受影响会话，审查仅含 trace ID 的安全事件。

## 退出和清理

停用时先禁止新任务和检索可见性，再创建可审计清除运行。完成后删除派生描述和向量，保留脱敏运行事件 180 天及聚合成本数据 24 个月。
