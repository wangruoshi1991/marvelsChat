# 妙讯运营后台完善设计

## 目标

将现有 React/Ant Design 后台收敛为唯一生产入口，并按成熟运营控制台的方式组织真实业务：账户中心、发布中心、运营中心、系统中心。每个工作域都同时提供列表、详情、状态、关联对象和受权限保护的操作。

## 设计边界

- `admin/index.html -> admin/src/main.jsx` 是唯一运行时入口；`admin/admin.js`、`admin/admin-core.js` 和旧模块文件作为历史审计资产保留，不参与构建入口。
- 只消费现有后端真实 API；缺失、403、数据库错误和空数据分别显示，禁止用前端样例数据补齐。
- 发布中心保持代码 registry、Agent release、产品版本和用户 entitlement 的独立状态，后台操作始终走服务端权限、幂等和审计。
- 任何用户启用仍必须由用户本人 consent；后台只能查看或撤销授权，不能代替用户授权。

## 信息架构

| 工作域 | 资源 | 主要能力 |
| --- | --- | --- |
| 工作台 | 运营总览 | 指标趋势、待审核发布、运行任务、每日明细 |
| 账户中心 | 用户与权限 | 用户列表、账号资料、会话、Agent 授权、审计与运行关联 |
| 发布中心 | Agent 发布、产品目录、媒体检索 | release identity/readiness、产品依赖门禁、发布状态、媒体运行控制 |
| 运营中心 | 任务管理、运行监控 | 任务筛选/详情/重试取消、Agent/用户/产品聚合、任务状态分布 |
| 系统中心 | 审计记录、服务配置 | 管理操作追踪、Agent run 详情、模型/媒体服务脱敏状态 |

## 交互原则

- 侧边栏只显示工作域和资源子项，当前资源同步 URL、面包屑和浏览器历史。
- 列表用于批量查找，详情抽屉用于完整合同、状态时间线和关联记录；操作按钮显示服务端错误和 request ID。
- 总览使用表格、趋势和待办列表承载信息，指标卡只作为摘要，不替代管理数据。
- 每个模块有独立加载、错误、空态和刷新状态，不共享旧 DOM 状态。

## 后端复用与新增边界

优先复用 `/api/admin/overview`、`/api/admin/users`、`/api/admin/agent-releases`、`/api/admin/products`、`/api/admin/tasks`、`/api/admin/monitoring`、`/api/admin/events`、`/api/admin/agent-runs`、`/api/admin/agent-readiness`、`/api/admin/agent-usage`、`/api/admin/model-status` 和媒体检索控制接口。仅在前端无法表达完整详情时补充只读详情接口，不复制数据库或引入前端假数据。

## 验收

- 本地和正式域名均只呈现 React 后台。
- 具备权限的管理员可以从工作台进入任一资源，完成列表、筛选、详情、状态操作并看到真实返回。
- 无权限、服务错误、空数据和过期会话均有明确界面。
- Admin syntax/test/build、仓库检查和正式后台只读冒烟均通过。
