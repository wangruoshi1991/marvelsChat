# 2026-11-16 聊天附件与自定义表情本地闭环

本阶段把普通聊天附件和本人自定义表情接到同一条真实链路：RN 选择器保留草稿状态，后端认证上传并持久化，消息使用稳定 ID 发送和精确重试，接收端按权限读取私有内容。普通附件只开放给 direct/group；Agent、UI Agent、workspace 和创作上下文会明确拒绝普通附件与自定义表情。

普通附件已支持图片和 UTF-8 文本文件的上传、纯附件消息、文字+附件消息、失败上传重试、私有图片网格、全屏分页查看、文件预览、系统相册保存，以及按消息类型显示回复/复制/查看/保存/预览/删除/撤回菜单。消息删除或撤回后不再暴露附件；群聊退出后保留历史但进入只读状态。

自定义表情第一阶段只允许本人收藏静态 JPEG/PNG/WebP。服务端会规范化为不带来源元数据的静态 PNG，限制 2 MiB 和 512px；RN 提供收藏列表、上传、删除、空态/失败态和小尺寸气泡渲染。收藏被删除后，仍有权限的历史消息继续可见；新消息不能继续引用已删除收藏。
