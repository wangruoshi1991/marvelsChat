# 2026-11-02 后台运营能力差距审查

本记录基于本轮工作区代码实读。它是优先级和验收清单，不能把历史线上发布或本轮代码落盘视为所有功能已闭环。具体完成状态、命令与隔离验收证据以 CURRENT 为入口。

## P0：权限、隐私与发布合同

| 项目 | 实读发现与影响 | 验收要求 |
| --- | --- | --- |
| 用户详情最小数据 | `admin-repository.js` 曾复用用户消息列表，返回 `lastContent`；前端未渲染仍不能消除 API 数据暴露 | 用户运营接口仅返回必要元数据；用私密哨兵验证响应不含正文 |
| 审计来源真实性 | 普通 `/api/events` 事件与后台事件进入同一日志表，客户端不能自行写入 `admin.*` 冒充操作审计 | 拒绝保留事件命名空间；真实后台操作保留操作者、目标、request ID |
| 明确的 Agent 创建入口 | 旧列表 GET 执行 registry 同步并隐式建草稿；页面只能编辑既有 release，无法说明如何上架 | 读取不写入；独立 registry 读取、显式创建 draft、review/publish、已发布身份新修订；运行 key/version/scopes 来自代码 |
| 统一身份与头像 | 原表单仅图形和文本色值，不能上传图片；发布后身份必须保持不可变 | 图形/图片统一合同；受管图片上传、真实解码/重编码、草稿认证预览、发布后公共读取、RN 与 Web 同步消费 |
| 产品多版本与用户 consent | 只建产品、无草稿编辑/下一版本；不能通过发新版本静默改变用户已接受合同 | 结构化表单、精确 published release/scopes、版本选择、draft only 编辑、显式版本操作；旧授权保留，升级需用户明确确认 |
| 受限管理员请求 | 前端无权限时不应仍发出 agents:manage 接口请求；产品运营有独立读取依赖入口 | 无权限页面不请求资源；products:read/write 账号使用产品发布依赖接口；所有服务端仍独立校验 |

以上 P0 项已由本轮代码、定向测试、隔离 PostgreSQL、HTTP 和浏览器证据核定完成；Build54 图片身份门禁仍按交接文档保持关闭，不能把草稿上传当作客户端已支持。

## P2：管理体验与质量

- 保留独立 URL、工作域导航、表格筛选/分页和详情工作流；指标卡只作概览，不替代资源管理。

- 继续保留历史后台源码、迁移和部署审计资产；删除须先证明无引用并获用户明确授权。
