## 本轮范围

蓝湖第一面 `064bd189-53ad-4627-a8e9-05e953e3e2b3` 明确展示“个人数字身份”、职业介绍、签名、地区/经验/语言标签。本轮补齐这组资料的数据库、本人编辑、公开展示及后台维护，不把整个第一面或全 App 标记为已还原。

已实现字段：`headline`（80 字）、`publicLocation`（120 字）、`experienceYears`（0–80 整数或 null）、`languages`（10 种允许语言的去重代码数组）。职业和年限属于用户自述，不等于平台认证。展示地区通过原生定位和已有地理解析接口获取城市/省份候选，由用户明确选择并保存；不从详细地址、社区或活动区域推断，也不自动公开定位结果。新字段省略时保留原值，空文本/空数组/null 表示明确清空；0 年和未填写分别处理。

9/16 后续编辑体验调整：默认只展开昵称、签名和展示地区，职业介绍/年限/语言折叠为选填信息；固定顶部保存，支持未保存退出确认、定位失败说明和系统权限入口。社区与活动区域单独选择，遵循独立隐私设置。未加入新定位原生桥接；使用已有 `getCurrentLocation → resolveLocation`。移除无实际头像效果的“头像文字”输入，同时保存时保留原值。蓝湖新版没有独立编辑页，本页采用第一面卡片/标签的视觉体系，不宣称是独立编辑设计稿的逐像素还原。

App 的“编辑小站资料”保存后立即更新本人卡片；未填写项目不显示标签。沟通语言展示实际选择的语言，不自动写成设计样例“双语沟通”。妙点明细与社区定位管理入口移到“其他”，不再混入职业标签。第一面标题改为“个人数字身份”，卡片头像、昵称、职业文字、横排统计和标签按本轮观察调整；统计仍是旧业务数据，合作与评分尚待独立业务接入。

`showBio` 在设置中改称“展示职业资料与简介”，同时控制新身份字段在公开主页、公开小站和社交列表的返回。本人和有权限管理员可编辑；后台继续用现有 `users:read / users:write`。后台保存不再顺带覆盖用户头像文字；输入保存期间禁用，错误保留输入，成功后刷新服务端资料。

## 保存一致性与隐私

- 本人和后台 schema 均拒绝未知字段，防止字段拼错却返回假成功。数据库同时约束年限和语言白名单/去重。
- RN 对提交身份字段核验保存响应，缺字段或值不一致明确报错。此核验不能代替后端正确发布。
- PATCH 返回是保存成功边界；取消随后全量同步导致“已保存却报失败”的路径。资料版本标记防止较早发出的 bootstrap 覆盖新资料，仍应用其他模块内容；设置同步只合并设置字段。
- 旧账号迟到的响应不能改变新账号；现有增量同步不含资料，继续正常处理通知和消息。
- 新字段不自动加入模型上下文，也不修改 GPS 信息。账号删除通过现有关联清除；项目没有账号导出 API，不宣称已验证导出。

## 发布顺序

新增迁移为 `031_station_profile_identity.sql`，历史迁移不改动。先在可恢复环境应用当前迁移（含已有未发布的 030），部署同版本后端，确认 bootstrap/公开资料/后台返回完整身份字段且 `/api/ready` 通过，再分发 RN 和后台。

新 RN/后台对新字段有明确依赖，不能先发客户端连接旧生产后端。没有加入缺字段填空的兼容策略。截至本次记录，未切换线上 release 或执行生产迁移。正式模拟器包为 `com.wangruoshi.miaoxun`，连接正式 HTTPS；新 Release 候选已构建，须待服务端迁移后安装。之前的独立 QA bundle `com.wangruoshi.miaoxun.identityqa` 已卸载，QA API 4391/管理台 5176 已停止；临时 `profileqa` 账号已从隔离数据库删除，生产不存在该账号。当前正式 App 仍使用原有 TGary 账号，旧数据未清除。
