# 2026-09-18 TestFlight 44

## 发布范围

本次目标是 iOS `1.0 (44)` TestFlight beta，只更新 `MiaoxunRN` 客户端并继续连接
`https://8.153.167.11`。本次不部署后端或管理台，不开启媒体检索 Provider、队列、预算或其他
生产开关，也不代表全项目已达到 App Store 正式发布标准。

Build 44 主要用于验证统一内容长按交互：聊天卡片为“分享 / 妙管家 / 复制 / 更多”，输入框为
“换行 / 妙管家 / 粘贴 / 更多”，3D / OOTD 为“分享 / 妙管家 / 编辑 / 更多”。菜单以实际触点
为中心，靠近屏幕边缘时只将动作向内展开；正式动作图标仍待设计资源替换。
