# 2026-09-18 TestFlight 44

## 发布范围

本次目标是 iOS `1.0 (44)` TestFlight beta，只更新 `MiaoxunRN` 客户端并继续连接
`https://8.153.167.11`。本次不部署后端或管理台，不开启媒体检索 Provider、队列、预算或其他
生产开关，也不代表全项目已达到 App Store 正式发布标准。

Build 44 主要用于验证统一内容长按交互：聊天卡片为“分享 / 妙管家 / 复制 / 更多”，输入框为
“换行 / 妙管家 / 粘贴 / 更多”，3D / OOTD 为“分享 / 妙管家 / 编辑 / 更多”。菜单以实际触点
为中心，靠近屏幕边缘时只将动作向内展开；正式动作图标仍待设计资源替换。

- 模拟器无障碍动作不能注入任意触点。左右侧触点、拖入放大与松手单次执行已有组件手势测试，
  但物理长按、拖动、震感以及 3D WebView 手势竞争仍须安装 Build 44 后在真实 iPhone 验收。
- 正式动作图标尚未交付；当前使用明确的 Lucide 语义图标，不宣称逐像素一致。
- 正式管理台响应仍缺仓库 Nginx 模板要求的安全头，因此整项目正式上线结论仍为阻塞；该问题
  不改变本次只更新 iOS TestFlight beta 的边界。
- Bundler 锁定的 CocoaPods gems 当前未安装；归档使用本机 CocoaPods 1.16.2，Pod lock 与已安装
  Pods 一致。不得把这一环境条件描述成全新机器可复现安装已经通过。
