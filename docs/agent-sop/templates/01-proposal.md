# Agent Proposal

- Agent key: `REQUIRED_AGENT_KEY`
- 暂定名称: `REQUIRED_NAME`
- 提交人: `REQUIRED_OWNER`
- 日期: `YYYY-MM-DD`
- 决策状态: `proposed | approved | rejected`

## 用户问题

用一句话描述目标用户遇到的问题。

## 目标任务

列出用户交给 Agent 的具体任务，以及每项任务的可观察结果。

## 为什么需要 Agent

说明为什么普通表单、搜索、规则或静态功能不足以解决该问题。

## 非目标

明确本版本不会做的事情，以及 Agent 禁止声称已完成的事情。

## 成功指标

至少包含成功率、用户完成率、P95 延迟、单位任务成本、人工介入率和 EvaluationSuite 质量阈值。异步 Agent 还要包含恢复成功率和事件回放成功率。

## 依赖

列出模型、工具、数据库、OSS、队列、App/Web、AgentCard、RuntimeStatus、事件/Checkpoint 和人工流程。

## 初步风险

列出敏感数据、费用、公开发布、外部发送、删除和不可逆操作。

## 负责人

填写 Agent Owner、Capability Owner、Client Owner、Security Reviewer 和 Release Owner。

## 批准

- 批准人: `REQUIRED_APPROVER`
- 批准时间: `REQUIRED_TIMESTAMP`
- 限制条件: `NONE_OR_EXPLICIT_CONDITIONS`
